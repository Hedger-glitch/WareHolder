# WareHolder - Warehouse Management API

REST API для управления складской системой. Проект позволяет вести учет поставщиков, складов, полок и товаров, а также управлять остатками на полках с проверкой бизнес-правил.

## Начало работы

### Требования

Для запуска проекта вам понадобятся:
- [.NET SDK](https://dotnet.microsoft.com/download) (версия 10.0 или выше)
- [PostgreSQL](https://www.postgresql.org/download/) (запущенный локально или в Docker)
- [Visual Studio 2022](https://visualstudio.microsoft.com/)

### Установка зависимостей и запуск

1. Клонируйте репозиторий:
  ```sh
  git clone https://github.com/Hedger-glitch/WareHolder
  ```
2. Перейдите в папку с проектом:
  ```sh
  cd WareHolder.Server
  ```
3. Настройте строку подключения к вашей базе данных в файле appsettings.json.
4. Примените миграции для создания структуры БД:
  ```sh
  dotnet ef database update
  ```
5. Запустите сервер:
  ```sh
  dotnet run
  ```
6. Перейдите по адресу https://localhost:7221/swagger (порт может отличаться), чтобы открыть Swagger UI и протестировать API.

## Архитектура и реализованный функционал

Проект построен по слоистой архитектуре:
- **Controllers** - обработка HTTP-запросов.
- **Services** - бизнес-логика.
- **DTOs** - объекты для передачи данных лишенные навигационных свойств (защита от циклических зависимостей).
- **Models / Data** - сущности БД и настройки Entity Framework Core.

**Реализованная бизнес-логика**

- Строгая валидация связей при создании полок (склад и поставщик должны существовать).
- Запрет на размещение товара на полке, если поставщик товара не совпадает с поставщиком, за которым закреплена полка.
- Логика управления остатками (при добавлении существующего товара на полку увеличивается его количество).
